# ChargeKaro website

Marketing website for ChargeKaro: find verified EV charging stations, pre-book a charging slot, and partner with us as a station owner.

A single static page with no build step: `index.html` plus `assets/`.

## Hosting on Netlify
- Publish directory: the repo root. There is no build command.
- The partner form in "For charging station owners" emails each request to chargekaroo@gmail.com through FormSubmit (formsubmit.co). No Netlify setting is needed.
  The very first submission sends an "Activate form" email to chargekaroo@gmail.com: click the link once, then every request arrives by email.
